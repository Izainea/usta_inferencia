Guía Técnica de Probabilidad

1. Fundamentos de Variables Aleatorias Discretas

Una variable aleatoria discreta X es una función que asigna un valor numérico a cada resultado posible de un experimento aleatorio.

1.1 Función de Probabilidad

Propiedades: \[p(x) \geq 0 \text{ para todo } x\] \[\sum p(x) = 1\]

2. Esperanza Matemática (Valor Esperado)

2.1 Definición Formal

\[E(X) = \sum x \cdot p(x)\]

2.2 Propiedades de la Esperanza

  • \(E(aX + b) = aE(X) + b\)
  • \(E(X + Y) = E(X) + E(Y)\)
  • \(E(aX + bY) = aE(X) + bE(Y)\)
  • Para una constante c: \(E(c) = c\)
  • Si \(X \geq 0\), entonces \(E(X) \geq 0\)

3. Varianza

3.1 Definición Formal

\[Var(X) = E[(X - \mu)^2] = \sum (x - \mu)^2 \cdot p(x)\] donde \(\mu = E(X)\)

3.2 Fórmula Computacional

\[Var(X) = E(X^2) - [E(X)]^2\]

3.3 Propiedades de la Varianza

  • \(Var(X) \geq 0\)
  • \(Var(aX + b) = a^2Var(X)\)
  • Si X e Y son independientes: \(Var(X + Y) = Var(X) + Var(Y)\)

4. Variables Aleatorias Continuas

4.1 Función de Densidad de Probabilidad (PDF)

Propiedades: \[f(x) \geq 0 \text{ para todo } x\] \[\int_{-\infty}^{\infty} f(x)dx = 1\]

4.2 Función de Distribución Acumulada (CDF)

\[F(x) = P(X \leq x) = \int_{-\infty}^x f(t)dt\]

4.3 Esperanza y Varianza

\[E(X) = \int_{-\infty}^{\infty} x \cdot f(x)dx\] \[Var(X) = \int_{-\infty}^{\infty} (x - \mu)^2 \cdot f(x)dx\]

5. Distribuciones Importantes

5.1 Distribuciones Discretas

Binomial:

\[P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}\] \[E(X) = np, \quad Var(X) = np(1-p)\]

Poisson:

\[P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}\] \[E(X) = Var(X) = \lambda\]

Geométrica:

\[P(X=k) = p(1-p)^{k-1}\] \[E(X) = \frac{1}{p}, \quad Var(X) = \frac{1-p}{p^2}\]

5.2 Distribuciones Continuas

Normal:

\[f(x) = \frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}\] \[E(X) = \mu, \quad Var(X) = \sigma^2\]

Uniforme:

\[f(x) = \frac{1}{b-a} \text{ para } a \leq x \leq b\] \[E(X) = \frac{a+b}{2}, \quad Var(X) = \frac{(b-a)^2}{12}\]

Exponencial:

\[f(x) = \lambda e^{-\lambda x} \text{ para } x \geq 0\] \[E(X) = \frac{1}{\lambda}, \quad Var(X) = \frac{1}{\lambda^2}\]

6. Fórmulas de Transformación

6.1 Transformación Lineal

Si \(Y = aX + b\), entonces: \[E(Y) = aE(X) + b\] \[Var(Y) = a^2Var(X)\]

6.2 Transformación No Lineal

Para \(Y = g(X)\): \[E(Y) = \int_{-\infty}^{\infty} g(x) \cdot f(x)dx\] \[Var(Y) = E[g(X)^2] - [E(g(X))]^2\]

7. Teoremas Fundamentales

7.1 Teorema de Bayes

\[P(A|B) = \frac{P(B|A)P(A)}{P(B)}\]

7.2 Ley de Probabilidad Total

\[P(A) = \sum P(A|B_i)P(B_i)\]

8. Producto de Variables Aleatorias

8.1 Variables Independientes

\[E(XY) = E(X)E(Y)\] \[Var(XY) = E(X)^2Var(Y) + E(Y)^2Var(X) + Var(X)Var(Y)\]

8.2 Variables No Independientes

\[E(XY) = E(X)E(Y) + Cov(X,Y)\] \[Var(XY) = E(X)^2Var(Y) + E(Y)^2Var(X) + 2E(X)E(Y)Cov(X,Y) + [Cov(X,Y)]^2 + E[(X-\mu_X)^2(Y-\mu_Y)^2] - Var(X)Var(Y)\]
Para variables normales correlacionadas: \[E[(X-\mu_X)^2(Y-\mu_Y)^2] = \sigma_X^2\sigma_Y^2(1 + 2\rho^2)\] donde \(\rho\) es el coeficiente de correlación

9. Límites y Convergencia

9.1 Teorema del Límite Central

\[\frac{\bar{X}_n - \mu}{\sigma/\sqrt{n}} \xrightarrow{d} N(0,1)\]

9.2 Ley de los Grandes Números

\[\bar{X}_n \xrightarrow{p} \mu\]
